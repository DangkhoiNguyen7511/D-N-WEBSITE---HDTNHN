# THPT Phú Nhuận — Website giới thiệu

Website giới thiệu **THPT Phú Nhuận, TP. Hồ Chí Minh** được xây dựng bằng HTML, CSS và JavaScript thuần, tập trung vào giao diện hiện đại, chuyển động mượt và trải nghiệm responsive trên máy tính lẫn điện thoại.

## ✨ Tính năng

- 🎬 Màn hình loading khi khởi động
- 🌌 Hiệu ứng particle chuyển động ở khu vực hero
- 🪄 Scroll Reveal khi cuộn trang
- 🖱️ Custom cursor và hiệu ứng hover
- 🧲 Nút tương tác/magnetic hover
- 🎴 Hiệu ứng 3D tilt cho các card
- 📊 Counter animation cho số liệu
- 🌊 Smooth scrolling giữa các section
- 🧭 Navigation tự nhận diện section đang xem
- 📱 Menu mobile responsive
- ✨ Hover, glow và transition cho các thành phần giao diện
- 🖼️ Hiệu ứng parallax cho khu vực hero

## 📁 Cấu trúc dự án

```text
D-N-WEBSITE---HDTNHN/
├── index.html
├── style.css
├── script.js
└── README.md
```

### index.html
Chứa cấu trúc và nội dung website.

### style.css
Chứa giao diện, responsive layout, animation, transition, glow, hover và hiệu ứng hình ảnh.

### script.js
Xử lý loading, particle, scroll reveal, counter, navigation, menu mobile, cursor và hiệu ứng 3D card.

## 🚀 Chạy website

Không cần framework hay thư viện phức tạp.

### Mở trực tiếp
Mở `index.html` bằng trình duyệt.

### VS Code
Mở thư mục dự án bằng VS Code và chạy bằng **Live Server** để có trải nghiệm tốt nhất.

## 🌐 GitHub Pages

Website có thể triển khai bằng GitHub Pages với branch `main`. Sau khi Pages hoàn tất triển khai, GitHub sẽ cung cấp địa chỉ website tương ứng với repository.
